EXPERIMENT 10(a)
Title: Load, Clean, and Explore Data using Python

ALGORITHM:
1. Start the program.
2. Import the Pandas library as pd.
3. Create a dictionary containing student names, ages, and marks. Include missing values.
4. Convert the dictionary into a Pandas DataFrame.
5. Display the original dataset.
6. Replace missing values in the Age column with the mean age using fillna().
7. Replace missing values in the Marks column with the mean marks using fillna().
8. Display the cleaned dataset.
9. Use info() to display information about the dataset.
10. Use describe() to display the statistical summary.
11. Use head(2) to display the first two rows.
12. Stop the program.
